# Cloud Slippers AW26 — Colourway Tech Pack

**8 new colourways. Style unchanged: same last, same knit construction, same sole
unit, same insole, same sizing, same packaging and labelling as current production.
Colour and pattern are the only variables.**

Each colourway below has two references attached:
- a **product render** — what the finished shoe should look like
- a **fabric swatch** — the pattern artwork at scale. **Each swatch represents a
  20 cm × 20 cm piece of fabric.** Count the motifs in the swatch to get the scale.

HEX values are the visual target for the yarn dye. Pantone TCX to be confirmed on
the approved lab dip.

---

## Rules that apply to all 8

1. **Patterns must be KNITTED IN (jacquard).** Never printed, never embroidered,
   never heat-transferred.
2. **Motif scale is the single most important spec on this pack.** A pattern that
   comes out too small is unusable for us — it disappears at thumbnail size online.
   Where a scale is given in cm, treat it as a hard spec, not a guideline.
3. **Strike-off required before bulk** on all 6 patterned colourways.
   **Lab dips required before bulk** on every base colour — 3 options each
   (target / lighter / darker).
4. **Colour fastness** to rubbing and to washing on all dark shades: no crocking
   onto light flooring or onto socks.
5. **Sole, insole, collar height and label**: unchanged from current production
   unless a colourway below says otherwise.
